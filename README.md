# Demo Project

A web application project featuring frontend components, security testing scripts, and Supabase integration.

## Project Structure

- `index.html` - Main application entry point
- `styles/` - Application stylesheets (`main.css`)
- `js/` - Frontend application logic (`app.js`, `store.js`)
- `supabase/` - Supabase database migrations and security policies
- `server.ps1` - PowerShell local server script
- `test_security.html` / `test_security.ps1` - Security trust layer validation and test suite
